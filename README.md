# АРФА TMS

**АРФА TMS** — MVP-прототип системы управления тестированием, разработанный в качестве дипломного проекта **Бурковым Никитой** (Nikbu).

Это функциональный прототип, построенный на современном стеке веб-технологий. Цель — продемонстрировать полноценную систему управления тестированием с реализацией основных рабочих процессов.

---

## Назначение

Проект является результатом работы над дипломной квалификационной работой. Это MVP — Система готова к эксплуатации с архитектурной точки зрения, но находится на уровне прототипа с точки зрения полноты функций.

## Текущий охват функций MVP

### ✅ Реализовано
- **Проекты** — создание, управление, завершение/реактивация, удаление; режимы наборов (единый, единый с базовыми линиями, несколько)
- **Тест-наборы и разделы** — иерархические разделы, перетаскивание для изменения порядка
- **Тест-кейсы** — полный CRUD, шаблоны (Текст, Шаги, Исследовательский, BDD, Чеклист), приоритеты, массовое редактирование/удаление/копирование
- **Тест-раны** — создание из набора, включение всех или конкретных кейсов, добавление результатов, массовое добавление результатов, закрытие/возобновление
- **Тест-планы** — группировка нескольких ранов, привязка к вехам
- **Вехи** — создание, завершение, под-вехи
- **Требования** — создание, привязка к тест-кейсам, организация по папкам
- **Отчёты** — дашборд проекта (сводка ранов, распределение статусов, активность во времени, покрытие кейсов, прогресс по вехам, нагрузка)
- **Задачи (To-Do)** — персональный список назначенных тестов по всем проектам
- **Управление пользователями и ролями** — администратор сайта, администратор проекта, ведущий, тестировщик, наблюдатель
- **Локализация** — английский и русский языки с логотипами под каждую локаль
- **Тема оформления** — светлая / тёмная с отдельными логотипами под каждую тему
- **Панель администрирования** — настройки сайта, управление пользователями
